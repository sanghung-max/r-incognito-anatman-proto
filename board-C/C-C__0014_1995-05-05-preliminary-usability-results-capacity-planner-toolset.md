## 觀景 / vista

The Capacity Planner Tool Set is an integrated knowledge-based software application
supporting the Future Method of Operation (FMO) for Tactical Planning Process in
Capacity Provisioning. It consists of the Capacity Analyzer (CA), the
Architectures/Models/Configurations (AMC) Qualifier and the Plan Outliner (PO). In
Release 1.0 of the Tool Set, only the Capacity Analyzer will be deployed. Subsequent
releases will include the other two modules as well as enhancements to Capacity Analyzer.


---

## 亂語 / text

The goal of this usability evaluation was to obtain feedback from Capacity Provisioning
Tactical Planners and other users on the Capacity Planner Tool Set Release 1.0. This
evaluation focused on the usability of Capacity Planner Tool Set as well as whether the
information provided by the Capacity Analyzer of the Tool Set supports analysis of loop
information.
The Capacity Planner Tool Set uses a graphical user interface designed to support tactical
planning activities of Capacity Provisioning. Release 1.0 of the Tool Set enables the
tactical planners to create new or open existing planning request for selected wire centers,
view the overall hierarchical organization of the wire center selected (route, CSA and DA)
and compare integrated forecasts of functional properties (FP) groups by location area to
existing and planned network functional capabilities. It also allows the users to modify
forecasts and capacity data as needed.

## 懸置 / epoché

Evaluations of the usability of the system were conducted in the Deer Creek Capacity
Provisioning Facilities in conjunction with the User Acceptance Testing of the System
Operations Group of Capacity Planner Tool Set. The participants were given a brief
overview of the Tool Set before they conducted user acceptance testing given by System
Operations. After the user acceptance testing, the participants completed a Usability Study
Questionnaire, a User Profile Inventory as well as a short Questionnaire designed to
assess their training needs. A total of 11 users (8 tactical planners, 2 prototype process
team members and 1 design engineer) participated in the study.
