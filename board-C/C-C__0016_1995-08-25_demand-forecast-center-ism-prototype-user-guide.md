## 觀景 / vista

The purpose of this document is to provide the forecasters in the
Demand Forecast Center with practical guide and tutorials of using the
Integrated Staffing Model Prototypе.

There are four tutorials covering various aspects of the prototype.
These include doing a simple forecast with ISM on the staffing level of
H&PS CMC agents, using ISM forecast on number of SA Technicians
and varying one external input variable, and a complex scenario of
conducting an ISM forecast of POTS I&M Technicians. The last tutorial
covers the use of a queuing model template independent of the ISM.

---

## 亂語 / text

The purpose for developing the ISM is to provide a forecasting method
which enables the DFC to more accurately anticipate the need for US
WEST call cenetr agents and field technicians and to strategically
posotion U S WEST to meet and evaluate this need within an
integrated framework.
The ISM incorporates a basic, high-level understanding of US WEST
operations, using the explanatory power inherent in causal models to
predict the staffing impacts of future corporate decisions.


---

## 懸置 / epoché

The prototype version of the ISM is intended to be a proof of concept.
The prototype links core processes of U S WEST operations using
available data and subject matter expert estimates to model the effects
of actions and decisions in one core process on other processes.
The ISM prototype has been built at a high level, considering the 14
state region to be the basic unit of geography and core processes to be
the basic unit of work groups.
The prototype version represents the first iteration of the the ISM System. One purpose of this prototype is to identify areas of
improvement and changes for the production system.

## 理解 / wissen

prototype is subject to the following limitations:
The user interface design reflects the optimal use of limited
resources and time rather than the optimal layout from the
usability or user interface standard perspective.
The input and output data may not be presented in a formatted and
easy-to-understand form.
